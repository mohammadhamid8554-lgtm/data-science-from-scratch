# Data Science From Scratch

A structured, hands-on repository documenting my end-to-end data science learning journey—from core Python fundamentals to numerical computing and data manipulation.

## Repository Structure

| Folder | Focus Area |
| :--- | :--- |
| `phase_0.1_python_basics` | Core Python syntax, data structures, control flow, and functions |
| `phase_0.1_projects` | Foundational Python mini-projects applying core programming concepts |
| `phase_0.2_python_for_data_work` | File handling (CSV/JSON), comprehensions, and data-oriented Python workflows |
| `phase_0.2_projects` | Applied data-processing scripts and practice projects |
| `phase_1.1_numpy` | Vectorized operations, array indexing, broadcasting, and numerical computing with NumPy |
| `phase_1.2_pandas` | DataFrames, data cleaning, grouping, merging, and exploratory analysis with Pandas |

## Tech Stack
* **Language:** Python 3
* **Libraries:** NumPy, Pandas
* **Environment:** Virtual Environment (`.venv`) & VS Code
